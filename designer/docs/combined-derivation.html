2026-11-21 · 원래 박스 구조를 실제로 확장한 연구·구현 기록

사다리꼴과 경사를 함께 접고,
같은 패널에서 다른 운동을 찾기

디자이너추가 회전 시뮬레이터이전 구조 검토

이전 버전은 “사다리꼴+경사는 아직 지원하지 않는다”는 경계에서 멈췄다. 이번에는 그 경계를 기하 문제로 풀었다. 위·아래 판을 합동 강체로 유지하는 연속 해를 유도하고, 새로운 직접 힌지형과 추가 회전 경로까지 구현했다. 아래 수식은 이 프로젝트의 모델에 대해 직접 유도한 것이다. 기존 학술 용어인 구면 링크와 야코비안 분석은 참고했지만, 새로운 학술적 발명을 주장하는 문서는 아니다.

1. 새로 가능해진 것

결과구체적으로 달라진 점
사다리꼴+앞뒤 경사앞뒤 너비와 앞뒤 높이를 함께 바꾼다. 상판을 늘리지 않고, 각 측벽 패널을 강체로 유지한다.
사다리꼴 직접 힌지한쪽 측벽을 제거한 구조도 사다리꼴로 만든다. 뒤/앞 높이 비율이 너비 비율과 같아야 한다는 조건을 유도했다.
추가 yaw 운동두 비율이 같은 특수한 6패널 구조에서는 같은 전개도로 추가 회전이 가능한 경로를 찾았다. 별도 연구 시뮬레이터에서 탐색한다.
목표에서 역설계최대 기울기와 앞 높이로 뒤 높이를 구한다. 특정 높이·기울기의 자세도 역으로 찾는다.
움직임의 구속 분석형상마다 자유도가 어떻게 달라지는지 수치 계산하고, 특이 자세와 구속이 약해지는 조합을 표시한다.
두께에 맞춘 끝 여유삼각 끝의 큰 판 두 장이 겹치던 반례를 찾고, 필요한 끝 물림을 각도와 판 두께로 계산한다.

2. 사다리꼴+경사형의 연속 접힘

바닥판 길이를 H, 앞뒤 너비를 W₀, W₁, 완전히 열린 앞뒤 높이를 h₀, h₁이라 두자. 중심을 맞춘 사다리꼴이고 위·아래 판은 합동이다. k=(W₀−W₁)/2, S=√(H²+k²)라 하자.

δ = asin((h₁ − h₀) / H),    |h₁ − h₀| < H
θ = progress × δ

앞 상판 모서리: y = h₀(cos θ − 1)/sin δ
               z = h₀ sin θ/sin δ
뒤 상판 모서리: y = H + h₁(cos θ − 1)/sin δ
               z = h₁ sin θ/sin δ

x좌표는 바뀌지 않는다. 두 뒤/앞 모서리의 y 차이는 H cos θ, z 차이는 H sin θ이므로 상판의 앞뒤 길이는 정확히 H다. 즉 상판은 x축과 평행한 고정 직선 주위에서 회전하는 합동 강체다. 화면에 맞춰 판을 늘리는 방식이 아니다.

측벽 패널은 어떻게 정하는가?

왼쪽 바닥 연결축과 상판 연결축을 연장하면 PL에서 만난다. 오른쪽도 PR에서 만난다. 이 두 점은 접힘 도중 움직이지 않는다. 한 측벽의 바닥축 단위 방향을 v, 현재 상판축 방향을 w라 하자. 가운데 접는 축의 방향 u가 두 축과 항상 같은 고정 각 β를 이루게 만든다.

sin β = (H/S) sin(|δ|/2)
u·v = u·w = cos β

u = cos β (v+w)/(1+v·w)
    ± √(1 − 2 cos²β/(1+v·w)) × (v×w)/|v×w|

두 부호 중 측벽이 안으로 접히는 분기를 선택한다. 각 모서리는 교점 P에서 일정한 거리 r만큼 떨어진 위치에 놓는다. 같은 측벽 패널 안의 두 점 간 거리는 r값들과 고정 내적 cos β로만 정해지므로 접히는 내내 변하지 않는다. 0 ≤ progress ≤ 1에서는 현재 축 사이 각도가 최대 각도를 넘지 않아 제곱근이 실수다. 완전히 닫히면 상판과 바닥판이 일치하고, 완전히 열리면 가운데 축이 각을 이등분한다.

이것은 이상적인 힌지축 모델의 연속 구성 증명이다. 양쪽 측벽의 교차를 막는 보수적인 너비 조건을 적용하고, 같은 측벽 내 접촉·판 두께·전개도·열린 전개도에서의 조립은 별도로 검사한다. 유한한 표본 충돌 검사만으로 모든 중간 자세의 무간섭을 증명했다고 표현하지 않는다.

코드는 원점에서 멀리 있는 P를 직접 빼지 않고 식을 정리해 계산한다. 높이 비율이 1에 가까워져 P가 멀어져도 오차가 크게 튀지 않게 했다. 기존 경사형은 W₀=W₁인 정확한 특수 경우이고, δ→0이면 평행한 사다리꼴의 기존 접힘으로 이어진다.

3. 사다리꼴 직접 힌지의 구속조건

사다리꼴의 왼쪽 변을 직접 힌지로 삼으면, 오른쪽 변과 왼쪽 변의 연장선은 같은 P에서 만난다. 상판을 왼쪽 변 주위로 돌려도 P는 고정된다. 남은 세 축도 P를 지나도록 만들면 구면 4R 링크가 된다. 반대쪽 측벽의 가운데 축은 위와 같은 두 원뿔 교차식으로 구할 수 있다.

앞 자유 모서리의 힌지까지 수직 거리 = W₀ H / S
앞 높이 h₀ = (W₀ H/S) sin θ
뒤 높이 h₁ = (W₁ H/S) sin θ

따라서 h₁/h₀ = W₁/W₀

이 비율은 사용자가 독립적으로 정할 자유 변수가 아니다. 한쪽 측벽을 끄면 남은 변수의 종속 관계가 바뀌는 것이다. API는 이를 parameterRelations로 반환하고, 입력이 어긋나면 필요한 비율을 오류에 포함한다. 이것이 잠금과 On/Off를 단순한 UI 장식으로 처리할 수 없는 구체적인 이유다.

새 해법은 너비 비율 0.5부터 2까지, 그리고 1±10⁻¹¹처럼 직사각형에 매우 가까운 조합에서도 검사했다. 좌우 어느 쪽을 직접 힌지로 만들든 동일한 강체 조건을 유지한다. 현재 최대 힌지각 범위는 기존과 같이 60° 이내다.

4. 가장 중요한 발견: 같은 비율일 때 운동 자유도가 바뀐다

6개 힌지축의 순간 나사 좌표 Sᵢ=[ωᵢ; aᵢ×ωᵢ]를 열로 쌓으면 폐루프 속도식 Jq̇=0이 된다. 바닥을 고정한 내부 순간 자유도는 6−rank(J)다. 회전과 병진 단위를 섞지 않도록 길이로 정규화했고, 자체 SVD 결과를 NumPy의 독립 SVD와 대조했다.

일반적인 내부 자세계산된 순간 자유도
직사각형 평행 박스3
너비 비율과 높이 비율이 서로 다른 복합형검사한 일반 자세에서 1
두 비율이 같은 복합형3
직접 힌지형검사한 일반 자세에서 1

두 측벽 교점의 x좌표는 ±(W₁h₀−W₀h₁)/(2(h₁−h₀))이다. 따라서 h₁/h₀=W₁/W₀이면 두 교점이 하나로 합쳐진다. 모든 6개 축이 한 점을 지나면 구면 6R이 되어 순간 폐합식의 독립 구속 수가 달라진다. 직사각형 평행 박스는 축들이 평행해지는 별도의 극한이다.

대각선 부근의 작은 특이값은 특정 운동의 구속이 수치적으로 약해진다는 뜻이다. 재료의 강성이나 힘을 직접 계산한 것은 아니다. 그렇지만 비율을 바꾸면 외형뿐 아니라 운동 공간의 차원까지 바뀔 수 있다는 사실은 파라미터·추천·제어 설계에 직접 영향을 준다. 정확히 닫히거나 최대 펼침에 도달한 자세에서는 순간 자유도가 추가로 늘어나는 특이점도 따로 취급한다.

분석 방법 참고: Lynch & Park, Modern Robotics — Closed Chains. 이 자료는 분석 방법의 근거이며, 위의 수치 결과는 이 프로젝트의 모델에서 계산했다.

5. 같은 패널로 추가 회전을 주는 경로

너비와 높이 비율을 모두 0.7로 정한 6패널 설계에서, 같은 패널을 유지한 채 상판에 작은 yaw를 추가하는 경로를 만들었다. 상판의 모든 점을 공통 교점 P 주위에서 Rz(yaw)Rx(θ)로 회전하고, 두 측벽의 가운데 축을 고정된 각도 원뿔의 교차로 다시 구한다.

패널 형상을 바꾸지 않는 yaw 경로를 101개 자세에서 검사했다. 시험 경로는 접힘 진행률 30–90%, yaw 최대 1.3°이며 대칭 0.3 mm 두께 모델에서도 충돌이 검출되지 않았다. 더 큰 yaw는 벽 패널의 도달 범위를 벗어나거나 판이 간섭할 수 있으므로 자동으로 가능한 척 늘리지 않는다.

추가 회전 시뮬레이터 열기 → Fold와 Yaw를 각각 바꾸거나 Play alternate path를 누르면 된다. 일반 디자이너에는 여전히 선택한 기준 경로를 보여준다. 이 페이지는 3자유도 공간 중 2변수 단면을 탐색하는 도구이며, 모든 가능한 자세를 매개화한 것은 아니다.

이것은 회전이 섞이는 구조의 기하 레퍼런스다. 하나의 공기 주입으로 그 yaw 경로가 자동으로 재현된다는 결과는 아니다. 필름·구속·하중을 어떻게 설계해야 그 경로를 선택할지는 다음 물리 연구다.

6. 삼각 끝의 두께 문제를 발견하고 수정한 과정

40개 조합을 넓게 검사할 때, 길이 100 mm·앞 높이 24 mm·뒤 높이 0·간격 2 mm·두께 0.3 mm인 일부 구조가 조립 끝에서 간섭했다. 가상 힌지축은 맞았지만 g/2=1 mm만 끝을 물려 자르는 것으로는 두꺼운 판이 서로 닿았다.

q sin(θ/2) ≥ (t/2) cos(θ/2)
q ≥ (t/2) cot(θ/2)

같은 두께 t를 양면으로 t/2씩 돌출시킨 두 판을 같은 거리 q만큼 물려 자르면 위 조건으로 교차를 피할 수 있다. 기존 조립 검사의 목표 자세인 75%에서 이 조건을 만족하도록 q=max(g/2, 계산된 최소 물림)을 적용했다. 이 값은 API의 derivedFabrication.rearApexReliefMm에 명시된다. 75%보다 더 닫을 때는 두께 간섭이 다시 생길 수 있으므로 기존 안전 범위 검사를 유지한다.

수정 뒤 40개 조합의 4,040개 접힘 자세와 2,040개 조립 자세를 다시 검사했다. 모든 이상적 강체 경로와 조립 표본 검사가 통과했다. 최대 강체 길이 오차는 5.69×10⁻¹⁴ mm, 최대 폐합 오차는 2.48×10⁻¹³ mm였다. 이 수치는 부동소수점 오차 수준이라는 의미이며 실물 제작 정밀도를 뜻하지 않는다.

7. 역설계와 커널/API/UI의 다음 모습

design.synthesize는 앞 높이와 최대 기울기에서 h₁=h₀+H sin δ를 구한다. 뒤가 바닥 아래로 내려가는 목표는 거절한다. design.solvePosture는 특정 높이·기울기를 만드는 진행률을 구하고, 직사각형에서 “기울기 0°”처럼 여러 자세가 같은 목표를 만족하면 유일하지 않다고 반환한다.

여기서 더 나아가야 할 점은 하나의 progress가 모든 액츄에이터의 상태를 뜻할 수 없다는 것이다. 기준 경로는 여러 운동이 가능한 설계에서 고른 곡선이다. 앞으로는 다음 셋을 구별해야 한다.

  1. Design: 바뀌지 않는 패널·힌지·재료·제작 정보.
  2. Configuration: 허용되는 운동 공간 위의 실제 자세. 설계마다 필요한 좌표 수가 달라질 수 있음.
  3. Motion path / control model: 그 공간에서 어떤 경로를 선택하고 압력·센서와 연결하는가.

이번 API에서는 기존 progress 기반 기준 경로를 유지하고, 추가 운동은 research.orientation으로 분명히 구분했다. 다음 안정 버전에서는 차원과 구속이 있는 configuration 계약을 먼저 설계하는 것이 좋다. 자연어 시스템도 “기울어져 올라가라”는 목표를 이 공간의 경로로 바꾸고, 기하 검증과 실제 제어 모델을 각각 거쳐야 한다.

현재 UI는 Worker API를 실제로 사용한다. 계산 요청은 ID로 대응하고, 설계 변경마다 revision을 확인해 오래된 결과를 버린다. 회전·줌은 받은 자세를 다시 그리므로 전체 검증을 반복하지 않는다. 숫자 입력은 130 ms 묶어서 처리한다. 테스트에서는 응답 순서가 뒤집혀도 요청이 섞이지 않는지와 거절된 요청 이후 회복되는지를 확인했다.

입력 형식 버전과 계산 알고리즘 버전도 분리했다. 같은 숫자라도 나중에 패널 물림·간섭 해법이 달라지면 전개도가 달라질 수 있다. 저장 파일에는 알고리즘 버전과 생성된 패널 데이터를 함께 남기고, 다시 열 때 동일하게 재현되는지 확인한다. 실험 레퍼런스는 이 저장 파일과 연결해야 한다.

8. 다음에 네가 고민할 문제와 제안하는 실험

이번 결과를 바탕으로 가장 먼저 결정할 것은 움직임을 강하게 한 경로로 유도할 것인지, 여러 운동을 허용한 뒤 외부 구속·제어로 선택할 것인지다. 어떤 구조가 “더 좋다”는 문제가 아니라, 설계 목표가 다르다.

  1. 평행 상승용이라면 직사각형과 약한 사다리꼴의 옆밀림·기울어짐을 비교해 보자. 이상 모델에서는 구속 수가 달라지지만, 실물에서는 필름이 얼마나 지배적인지 확인해야 한다.
  2. 회전을 함께 만들려면 두 비율이 같은 특수 구조에 스트랩·비대칭 필름·외부 가이드를 주어 yaw 경로를 선택할 수 있는지 시험해 보자. 압력을 독립 제어할 수 없는 자유도까지 제어 가능한 것으로 가정하지 않는다.
  3. 파라미터 UI는 모든 숫자를 항상 독립적으로 열어두지 않는 편이 맞다. 직접 힌지 On/Off가 바뀌면 필요한 등식과 파생값도 바뀌어야 한다.
  4. 실험 기록에는 목표 궤적뿐 아니라 실제 상판 6D 자세, 압력, 하중, 반복 방향을 남겨야 한다. 그래야 운동 공간과 실제 선택 경로를 구분할 수 있다.

우선 제작 비교용으로 바닥 면적과 앞뒤 평균 높이를 맞춘 4개 후보를 examples/experiments/에 남겼다. 힘 성능 비교의 모든 변수를 통제한 실험은 아니며, 운동 구속을 비교하기 위한 출발점이다.

9. 재현 방법과 한계

node tests/run.mjs
node build-combined-research.mjs
python verify-mobility.py
node build-research-visuals.mjs
node server.mjs

관련 코드: kernel/combined.mjs, kernel/tapered-hinge.mjs, kernel/spherical-motion.mjs, kernel/mobility.mjs, kernel/posture.mjs, kernel/fabrication.mjs. 수치 기록은 verification/combined-research.json과 verification/independent-mobility.json에 있다.

모든 강체 거리·전개·조립 검사는 계속 실행한다. 끝벽 필름, 밀봉 가능성, 압력에 따른 평형, 실제 힘·강성·피로, 연속 두께 충돌 인증은 아직 남아 있다. 여기서 찾은 회전 경로가 Kresling 구조와 같은 물리 동작을 낸다고 주장하지 않는다.
